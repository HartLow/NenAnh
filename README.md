Công cụ nén ảnh trực tuyến với giao diện đơn giản, cho phép nén nhiều ảnh cùng lúc với chất lượng cao.

![image](https://github.com/user-attachments/assets/9177e754-4c4d-4ecc-85d3-59fa8ede412a)

## Tính Năng Cơ Bản

- 🖼️ Nén không giới hạn số lượng ảnh
- 🎯 Tùy chỉnh chất lượng nén (1-100%)
- 📱 Giao diện thích ứng đa thiết bị
- 🔍 Xem trước ảnh với công cụ zoom
- 💾 Tải xuống tất cả ảnh đã nén
- 🌐 Hỗ trợ đa ngôn ngữ (Tiếng Việt, English)
- ⚡ Xử lý nén nhanh chóng

## Cách Sử Dụng

1. Kéo và thả ảnh hoặc nhấp vào nút "Chọn Ảnh"
2. Điều chỉnh chất lượng nén theo ý muốn
3. Nhấn nút "Nén Ảnh" để bắt đầu quá trình nén
4. Tải xuống ảnh đã nén

## Công Nghệ Sử Dụng

- HTML5 Canvas cho việc nén ảnh
- Bootstrap 5 cho giao diện
- JavaScript thuần (Vanilla JS)
- CSS3 cho hiệu ứng và animation

## Cài Đặt

1. Tải xuống toàn bộ mã nguồn
2. Mở file `index.html` trong trình duyệt web
3. Hoặc triển khai lên web server
